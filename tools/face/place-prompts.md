# Prompts for Reem's places

Each prompt follows the bot's own description of the place (`PICTURE.LOCATIONS` in `worker.js`). If a picture
doesn't match its description, klein mixes the two, so keep to the details listed.

**How to make them**
- Square (1:1). Any size works: I crop each one and shrink it under 512x512 (klein's limit).
- Make the **day** picture first. For the **night** picture, start from your day picture and use the image
  generator's edit mode (attach the day picture, then paste the night prompt), so the room stays the same.
- Leave out people, pets and text. If a tool adds a person, add "nobody in the picture" at the end.
- Send them named like `living day`, `living night`. I'll check each one at full size against its description
  before it goes in.
